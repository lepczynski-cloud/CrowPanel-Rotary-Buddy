# Project card images

These four preview images belong to projects created by the same author. They are
committed to the repository so the website displays them even when GitHub API
requests, external images or build-time downloads are unavailable.

| Bundled file | Authentic source | Type |
| --- | --- | --- |
| `web/assets/projects/m5.webp` | `M5Stack-Touch-Control-Deck/images/m5stack-touch-control-deck.jpg` | Photo of the real device on a desk |
| `web/assets/projects/scratch.webp` | `sb-to-html-converter/assets/readme/app-preview.png` | Screenshot of the actual converter UI |
| `web/assets/projects/ascii.webp` | `ascii-camera-studio/public/assets/og/ascii-camera-studio.png` | Project-created side-by-side preview of original image and ASCII output |
| `web/assets/projects/admin.webp` | Screenshot of `admin-toolkit/public/index.html` rendered with its original `public/assets/css/styles.css` | Screenshot of the actual home page and tools |

All four images were converted to 960 × 540 WebP using Pillow with source-faithful
scaling/cropping. No synthetic device photos were generated. Browser-tool images
are app previews, not hardware photography.

The two matching square photos at the top of `README.md` are cropped copies of
`web/assets/rotary-buddy-real.webp` and `web/assets/rotary-buddy-dns.webp`.
The original photos remain unchanged for the live website's hero.
